# Changelog

Versions use `YY.M.N`. Newest first.

## 26.10.3 — 2026-10-17
- **Email alerts no longer copy the sender.** The message was addressed to the sender with the recipients in Bcc, so the sender's own mailbox received every alert, even when it was not in the recipient list. Now the recipients are the only ones who receive it (the sender gets a copy only if it is listed as a recipient).
- **Tip jar card** in Settings → Help & About: a small card with the tip jar, one line and a button that opens the tip page of onairgarage.com in your language (English, Italian, Spanish). Nothing elsewhere, no pop-ups.
- Dependencies updated: Electron 44.9.0, nodemailer 10.1.2, basic-ftp 6.2.3, and the other minor and patch updates of the lock file (`npm audit` reports no vulnerability in the dependencies that ship with the app).

## 26.10.2 — 2026-10-14
- **Guided update, the same in every OnAir Garage app.** The bar now has **Download and install**, **Remind me later** (24 hours), **Skip this version** and **Release notes**; the download shows a progress bar and can be **cancelled** (the partial file is removed; a download that stops for a minute is given up and cleaned). **Close and install** first saves a **safety copy** of your settings (`backups/pre-update-<version>.json`, the last 3 are kept) and **refuses while a show is being produced**, telling you which one. After the update the first start shows **Updated to…** and a **What's new** window with the changes of the version. Settings → Updates shows the date of the last check and has **Check now**.
- **Back to normal alert.** After an error or a "source not updated" alert, the first production that completes correctly sends one "Back to normal" message on email and Telegram (a switch per channel, on by default). It also works after a restart: what was announced is kept in `alert-state.json`.
- **Summary**, off by default (Settings → Alerts): what every show did in the last 24 hours (every day) or 7 days (every Monday), at the times you choose, always or only when something needs attention, on the channels that are switched on; once per time and day, also after a restart, and at the first start if the PC was off. **Send now** to try it.
- **Same look as the other apps.** Settings now has the pages General, FTP, Alerts, Categories, Updates, Backup and Help & About. **Show password** (eye) buttons on the SMTP password, the Telegram token and the FTP passwords. **Name of this installation**: every alert starts with `[FlowCast · name]` (the computer name if empty). **Help & About** with **Copy support info** (never settings, addresses or passwords) and **Open logs folder**. Logs: one file per day (`flowcast_dd-mm-yyyy.log`, 5 MB at most, the last 7 days kept). The window remembers its size and position. New option **Keep this PC awake**.
- **Common settings and backup format.** Settings are saved in the shape shared by the other apps (`notifications.email`, `notifications.telegram`); the old keys are still read and rewritten at the first start, so nothing is lost. The backup file now has `app`, `exportedAt` and, when secrets were left out, `emptiedSecrets`; a backup of another program is refused; after an import FlowCast also lists the secrets the file left out. Older backup files still import. What belongs to this PC (window position, update choices, installation name) is never in a backup.
- Repository: `CLAUDE.md` points to the OnAir Garage standard; shared modules (`updater`, `secrets`, `backup`, `alert-state`, `notify`, `logs`, `support`) carry a `garage-common` version line. The `updater` module has the interrupted-download fix (version 2): the partial file is closed before it is deleted, also when the download is cancelled, stalls or the final rename fails, and leftovers are removed at startup.
- The in-app Guide (English, Italian, Spanish), the PDF manuals and the README describe all of the above. Texts in English, Italian and Spanish (same keys in all three, checked by a test). Unit tests (`npm test`) run before every build.

## 26.10.1 — 2026-10-10
- **Alerts rebuilt on the common OnAir Garage rules.** Email goes to several recipients in **one message, all in Bcc** (nobody sees the others' addresses); the recipients are now one field, separated by commas. With an SMTP user name the connection **must be encrypted** (STARTTLS, or SSL/TLS from the start): the password never travels in clear text. Timeouts of 15 s (connection), 15 s (greeting) and 20 s (socket); Telegram 15 s per call.
- **Every alert is tried three times**: right away, again after 10 s and again after 60 s, on both email and Telegram. A channel that fails does not stop the other.
- **Alerts remember what they already said**: the "source not updated" count and the new-version notice survive a restart (new file `alert-state.json`, never part of a backup).
- **Passwords and tokens are encrypted on disk** (SMTP password, Telegram bot token, FTP passwords of shows and bookmarks) with the system keystore (Windows DPAPI, macOS Keychain, Linux Secret Service). Values saved in plain text by earlier versions are encrypted at the first start. Where no keystore exists they are kept as before and Settings → Email says so. They cannot be read on another PC or user account.
- **Backups**: the export has a box **Include passwords and tokens**, off by default. Off, the file has no passwords or tokens; on, a red warning is shown and they are written in plain text. After an import without them FlowCast lists what must be typed again and keeps what the PC already has for the same server and user. Older backups (with passwords) still import.
- **Passwords and tokens are masked** (`***`) in error messages and logs: SMTP password, Telegram token (it is part of the Telegram address) and FTP passwords.
- **New-version notice on desktop, Telegram and email**, once per version (Settings → Info → Updates; it needs Telegram or email switched on). A version is marked as announced only after the message was delivered, so a failed send is tried again at the next check.
- **Categories**: a new button renames a category in all its shows and keeps its colour; another deletes it and asks where to move its shows (another category or *No category*). Renaming into a name that already exists merges the two (Settings → General → Categories and colors).
- The Telegram text always says it comes from FlowCast, for bots shared with other programs.
- The in-app Guide (English, Italian, Spanish), the PDF manuals and the README describe all of the above.
- Unit tests (`npm test`) run before every build.
- Texts in English, Italian and Spanish (same keys in all three, checked by a test).
